# Jose Elmar Acuno Portfolio

This is a static portfolio website for Jose Elmar Acuno, built with plain HTML, CSS, and JavaScript.

## Local development

Open `index.html` in a browser, or run a local static server from the project folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

The project is configured for Firebase Hosting.

```bash
npm install
firebase deploy
```

## Git sync

This project can be pushed to GitHub and cloned on any other device for editing.
